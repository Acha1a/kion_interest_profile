# kion_interest_profile

Эксперимент с рекомендациями на датасете KION:
сравнение градиентного бустинга и компактного жанрового профиля.

## Запуск

1. Установить зависимости: `pip install -r requirements.txt`
2. Поместить файлы датасета в корень проекта.
3. Запустить: `python main.py`

Файлы датасета в репозиторий не включены.
