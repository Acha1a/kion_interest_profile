# KION: компактный профиль интересов пользователя

Исследовательский проект по автоматизации формирования признаков для рекомендательной системы на данных KION. Сравниваются градиентный бустинг на вручную подготовленных признаках и альтернативный подход — компактный профиль жанровых интересов пользователя. Популярность используется как базовая контрольная рекомендация.

## Цель

Проверить, может ли компактное представление пользовательских интересов по жанрам стать полезной альтернативой ручному конструированию признаков для рекомендательной модели.

Ключевые требования проекта:

- использовать градиентный бустинг как baseline-модель;
- соблюдать временной порядок данных и исключить утечку будущих взаимодействий;
- обучать и оценивать модели на временных разбиениях;
- сравнивать подходы с помощью метрик ранжирования;
- использовать популярность как sanity check — простую контрольную стратегию.

## Данные

Использован датасет KION.

| Показатель | Значение |
|---|---:|
| Взаимодействия | около 1,59 млн |
| Пользователи | 567 588 |
| Объекты | 12 693 |
| Период событий | 2021-03-13 — 2021-08-22 |

Данные о взаимодействиях содержат `user_id`, `item_id`, `last_watch_dt`, `total_dur` и `watched_pct`. Метаданные объектов включают жанры, тип контента, год выпуска и другие характеристики. Для пользователей доступны демографические признаки.

Дубликаты пар «пользователь — объект» отсутствуют; жанры заполнены для всех объектов.

## Подходы

### 1. Популярность

Контрольная стратегия ранжирует объекты по популярности. Она нужна, чтобы проверить, превосходят ли более сложные подходы простую рекомендацию наиболее востребованного контента.

### 2. Компактный профиль жанровых интересов

Для пользователя формируется компактное представление на основе жанров объектов из его доступной истории взаимодействий. Идея подхода — заменить часть ручного конструирования признаков агрегированным описанием предпочтений пользователя.

### 3. Градиентный бустинг

В качестве baseline использован `HistGradientBoostingClassifier` из scikit-learn. Модель обучалась на 400 000 парах: 80 000 положительных и 320 000 отрицательных.

Основные параметры:

| Параметр | Значение |
|---|---:|
| `max_iter` | 100 |
| `max_leaf_nodes` | 15 |
| `learning_rate` | 0.08 |

## Временное разбиение и защита от утечки

Разбиения формируются по времени: признаки пользователя строятся только на основе информации, доступной до соответствующего момента предсказания. Будущие относительно целевого события взаимодействия не используются при расчёте истории.

Для внутренней валидации применён временной cutoff `2021-07-17`:

| Часть | Взаимодействия | Eligible users |
|---|---:|---:|
| Обучающая история | 1 006 614 | — |
| Валидация | 266 983 | 43 325 |

Для финального тестирования использован cutoff `2021-08-04`:

| Часть | Взаимодействия | Eligible users |
|---|---:|---:|
| Обучающая история | 1 273 597 | — |
| Финальный тест | 321 189 | 53 282 |

При построении истории и целевых меток также использовалось временное разделение с cutoff `2021-06-20`. Финальный августовский тест не применялся для настройки моделей.

В кандидатном каталоге присутствовало 92,91% тестовых событий.

## Метрики

Качество рекомендаций оценивалось метриками ранжирования:

- **Recall@10** — доля релевантных объектов, найденных среди первых десяти рекомендаций;
- **NDCG@10** — качество ранжирования релевантных объектов с учётом их позиции в списке.

## Результаты

Все приведённые ниже метрики рассчитаны на выборке из 1 000 пользователей.

### Внутренняя валидация

| Подход | Recall@10 | NDCG@10 |
|---|---:|---:|
| Компактный жанровый профиль | 0.0031 | 0.0021 |
| Популярность | 0.1304 | 0.0792 |
| Градиентный бустинг | **0.1358** | **0.0814** |

На внутренней валидации градиентный бустинг показал лучший результат среди трёх подходов. Жанровый профиль в текущей реализации существенно уступил популярности.

### Финальный тест на августовских данных

| Подход | Recall@10 | NDCG@10 |
|---|---:|---:|
| Популярность | **0.1318** | **0.0819** |
| Градиентный бустинг | 0.1317 | 0.0804 |

На финальном тесте качество градиентного бустинга оказалось практически равным популярности, но немного ниже по обеим метрикам. Результат внутренней валидации, таким образом, не подтвердился на тестовом периоде.

## Выводы

- Градиентный бустинг немного превзошёл популярность на внутренней валидации.
- На финальном августовском тесте популярность показала немного лучшие Recall@10 и NDCG@10.
- Компактный жанровый профиль в текущей реализации не обеспечил конкурентного качества.
- Результаты указывают, что одной агрегации по жанрам недостаточно; дальнейшие улучшения могут потребовать более информативного представления пользовательской истории и дополнительной настройки формирования кандидатов.
- Тестовые результаты следует интерпретировать с учётом того, что они рассчитаны на выборке из 1 000 пользователей.
